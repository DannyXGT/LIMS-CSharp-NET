# Decisiones abiertas

Cada punto permanece marcado como **REQUIERE CONFIRMACIÓN DEL LABORATORIO**:

- si el reemplazo usa CAS + catálogo, incluye lote o admite múltiples lotes activos;
- qué hacer cuando CAS o catálogo están vacíos;
- si un alta reemplaza todos los candidatos o exige selección humana;
- vigencia de 366 días para estándar/stock;
- vigencia de 188 días para intermedia/curva;
- vigencia de 2 días para AQS;
- validez metrológica y unidades de F-09 y F-11;
- justificación de Disperse Dyes `/5`;
- alcance de entrada manual para Metales y SCCP;
- semántica y consumo correcto de una copia de intermedia;
- si curva consume por código o por componente;
- umbral único de `Por Vencer` (el legado usa 30, 60 y 120 días);
- catálogo definitivo de métodos, unidades y ubicaciones;
- asignación de permisos a roles existentes.

## Decisión segura temporal

El reemplazo automático está desactivado. Por tanto, jamás se reemplaza un material por coincidencias vacías ni se toma una decisión silenciosa sobre lotes. El índice CAS + catálogo no es único y la política podrá incorporarse en dominio sin cambiar el contrato principal.
